# Prompt Templates

## Part Report

Use this template when generating `report`:

```text
[PXX] <part_title>：输出可复用讲义。
结构：结论、证据链、反方检验、常见误判、3条行动。
语言：zh_Hans。禁止空话。
```

## Part Quiz

Use this template when generating `quiz`:

```text
[PXX] <part_title>：生成8-12题测验，含答案与1句解释。语言：zh_Hans。
```

## Part Flashcards

Use this template when generating `flashcards`:

```text
[PXX] <part_title>：生成术语与原则闪卡，要求可复习。语言：zh_Hans。
```

## Part Video

Use this template when generating `video`:

```text
[PXX] <part_title>：做视频讲解，先结论后证据，节奏紧凑。语言：zh_Hans。
```
