# mono-claw-xhs

XHS + HardThing 4-part end-to-end production repo.

Run:
```bash
source setting-api.sh
python3 -m pip install -r requirements.txt
npm install
python3 scripts/pipeline_orchestrator.py --stage check-env
bash scripts/verify_offline.sh
bash scripts/verify_live.sh
bash scripts/run_coverage.sh
```

Repro rule:
- Use only this repo + `setting-api.sh` + installed dependencies.
- Secrets/API defaults are loaded from `setting-api.sh` (or `.env.local` generated by `bash setting-api.sh --write-env`).

NotebookLM split skill:
```bash
python3 skills/notebooklm-book-pipeline/scripts/split_book_for_notebooklm.py \
  --book "resources/books/The Hard Thing About Hard Things.epub" \
  --target-parts 4 \
  --out-dir state/runtime/book_pipeline/hard-thing-skill

python3 skills/notebooklm-book-pipeline/scripts/run_notebooklm_book_pipeline.py \
  --split-manifest state/runtime/book_pipeline/hard-thing-skill/split_manifest.json \
  --notebook-id 01f1afb7-32da-485f-bf68-b0bb2b8e6bef \
  --artifacts report,quiz,flashcards \
  --limit-parts 1
```
